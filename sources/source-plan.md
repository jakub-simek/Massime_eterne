# Source Plan

## Prioritized Text Sources

1. IntraText, *Massime eterne*
   - Role: first digital base text.
   - URL: `https://www.intratext.com/ixt/itasa0000/_IDX084.HTM`
   - Printed source named by IntraText: S. Alfonso Maria de Liguori, *OPERE ASCETICHE*, Vol. IX, pp. 381-395, Edizioni di Storia e Letteratura, Roma 1965.
   - Status: used for download and first-pass TEI conversion.

2. Prints and facsimiles of historical editions
   - Role: control sources for transmission, variants, and historical print layout.
   - Status: still to be researched and documented bibliographically.

3. German translations
   - Role: comparison and reception sources, not automatically the basis for the working translation.
   - Status: still to be researched.
